NPURE E-Katalog by Elsa
Customer-facing e-catalog for NPURE skincare products, managed by BA NPURE Elsa at Najmia Unnes store.

Setup
Copy .env.local.example to .env.local and fill in Supabase credentials
npm install
npm run dev
Deploy to Vercel
Push to GitHub
Import repo in Vercel
Set environment variables:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
Deploy
